# 📝 JavaScript Notes App

A simple and responsive Notes App built using **HTML**, **CSS**, and **Vanilla JavaScript**. It allows users to create, edit, delete, search, and store notes directly in the browser using **Local Storage**.

## ✨ Features

* ➕ Create new notes
* ✏️ Edit existing notes
* 🗑️ Delete notes
* 🔍 Search notes in real time
* 💾 Automatically saves notes using Local Storage
* 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

## 📂 Project Structure

```text
├── index.html

```

## 🚀 Getting Started

1. Clone this repository:

```bash
git clone https://github.com/Karan-raut7/Javascript_Note_app.git
```

2. Open the project folder:

```bash
cd Javascript_Note_app
```

3. Open `index.html` in your browser.

No installation or dependencies are required.
